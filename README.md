# 🎮 BattleCity Unity Remake

![Unity](https://img.shields.io/badge/Unity-2022.3+-000?style=for-the-badge&logo=unity)
![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)
![2D](https://img.shields.io/badge/2D-Игра-green?style=for-the-badge)

Современный ремейк классической игры BattleCity, созданный на Unity, с однопользовательским и многопользовательским режимами, множеством уровней, бонусами и интеллектуальными вражескими ИИ.

## 🎯 Особенности

### ✅ Реализовано
- **Однопользовательская кампания** с 5+ уровнями
- **Многопользовательский режим** для 2 игроков
- **Интеллектуальные вражеские ИИ** с различным поведением
- **Система бонусов** с различными усилениями
- **Разрушаемое окружение** с разными типами стен
- **Система очков** и отслеживание статистики
- **Меню паузы** и управление состояниями игры
- **Настраиваемые параметры** (управление, имена игроков, цвета танков)

### 🎮 Режимы игры
- **1 ИГРОК** - Классическая однопользовательская кампания
- **2 ИГРОКА** - Кооперативный многопользовательский режим
- **НАСТРОЙКИ** - Настройка игрового процесса
- **О СОЗДАТЕЛЯХ** - Информация о разработчиках

## 🚀 Быстрый старт

### Предварительные требования
- Unity 2022.3+
- Базовые знания C#
- Git (опционально)

### Установка
1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/your-username/battlecity-unity.git
   cd battlecity-unity
   ```

2. **Откройте в Unity**
   - Запустите Unity Hub
   - Добавьте проект с диска
   - Откройте проект

3. **Настройте сцену**
   - Откройте `Scenes/MainScene.unity`
   - Убедитесь, что все менеджеры присутствуют в сцене
   - Настройте префабы игроков и тайлмапы

4. **Запустите игру**
   - Нажмите Play в редакторе Unity
   - Протестируйте все режимы игры

## 🎯 Игровая механика

### Управление танком
- **Игрок 1**: 
  - Движение: `WASD` 
  - Стрельба: `Пробел`
- **Игрок 2**: 
  - Движение: `Стрелки` 
  - Стрельба: `Enter`

### Типы врагов
| Тип | Здоровье | Очки | Поведение |
|------|--------|--------|----------|
| Базовый | 1 HP | 100 | Случайное движение |
| Продвинутый | 2 HP | 200 | Преследует игрока |

### Бонусы
- **❤️ Здоровье** - Восстанавливает здоровье танка
- **🛡️ Щит** - Временная неуязвимость
- **⚡ Скорость** - Увеличенная скорость движения
- **🔥 Скорострельность** - Более быстрая стрельба
- **💥 Усиленная пуля** - Увеличенный урон

### Прогрессия уровней
1. **Уровень 1-2**: Базовые враги, простые карты
2. **Уровень 3-4**: Смешанные типы врагов, сложный рельеф
3. **Уровень 5+**: Продвинутый ИИ, сложные layouts

## 🛠️ Руководство по разработке

### Добавление новых уровней
1. Создайте новый тайлмап в `Tilemaps/`
2. Спроектируйте layout уровня в редакторе Unity
3. Добавьте конфигурацию уровня в `Config/Levels/`
4. Обновите `MapGenerator.cs` для включения нового уровня

### Создание новых бонусов
1. Расширьте enum `PowerUpType`
2. Добавьте реализацию в `PowerUp.ApplyPowerUp()`
3. Создайте спрайт в `Sprites/PowerUps/`
4. Обновите логику появления в `EnemySpawner.cs`

## 🎮 Управление игрой

### Основные элементы интерфейса
- **Счетчик врагов** - оставшееся количество вражеских танков
- **Счетчик жизней** - количество оставшихся жизней игрока
- **Индикатор уровня** - текущий уровень игры
- **Таблица статистики** - результаты после завершения уровня

### Игровые состояния
- **Меню** - выбор режима игры и настроек
- **Игра** - основной игровой процесс
- **Пауза** - приостановленная игра
- **Завершение** - окончание игры (победа/поражение)

## 🔧 Технические особенности

### Архитектура
- **Модульная система** - независимые компоненты
- **Менеджеры** - централизованное управление системами
- **Событийная система** - коммуникация между компонентами
- **Пул объектов** - оптимизация производительности

### Оптимизация
- **Пул пуль** - переиспользование объектов
- **Tilemap** - эффективное создание уровней
- **Object Pooling** - для врагов и эффектов
- **Event System** - минимальные зависимости
